## TDD Red-Green-Refactor Cycle
Each feature follows strict TDD:
1. Write failing test FIRST
2. Run test, verify failure
3. Write minimal code to pass
4. Run test, verify pass
5. Refactor, keep tests green
6. Commit

## Quality Gates (Mandatory)
- [ ] All tests green (cargo test --release)
- [ ] Zero clippy warnings (cargo clippy --all-targets --release)
- [ ] Code format clean (cargo fmt --check)
- [ ] Doc tests pass (cargo test --doc)
- [ ] No panics in production paths (panic=abort in release)
- [ ] Humanizer v2.11.2 + antislop v3 applied to all public text
- [ ] Identity boundary: ZERO personal names in code/docs

## Risk Mitigation
- Encoding issues: test UTF-8, UTF-16, Latin-1
- Performance cliff: profile before shipping
- Tokenizer accuracy: validate against real GPT-2 BPE on sample set
- Dependency rot: lock versions, audit weekly
